Blockchain Registry API Documentation

Blockchain-powered registry with peer-to-peer validation and tokenized credits.
RESTful API for registering, submitting, and retrieving validated data.

API Endpoints

POST /api/register

Register a new UUID and get an access key.

Request: 
{
  "uuid": "your-uuid-here"
}
Response: 
{
  "uuid": "your-uuid-here",
  "key": "generated-access-key"
}
Linux/Mac Windows 
curl -X POST http://localhost:8080/api/register \
  -H "Content-Type: application/json" \
  -d '{"uuid": "12345678-1234-1234-1234-123456789abc"}'
curl -X POST http://localhost:8080/api/register -H "Content-Type: application/json" -d "{\"uuid\": \"12345678-1234-1234-1234-123456789abc\"}"
POST /api/submit

Submit data for validation on the blockchain.

Request: 
{
  "uuid": "your-uuid-here",
  "key": "your-access-key",
  "data": {
    "location": { "latitude": 12.345, "longitude": 67.890 },
    "area": 1000,
    "shape": "rectangle",
    "type": "restoration",
    "speciesData": ["Mangrove", "Seagrass"]
  }
}
Response: 
{
  "submissionId": "generated-submission-id",
  "status": "waiting" | "validated",
  "preValidated": true
}
Linux/Mac Windows 
curl -X POST http://localhost:8080/api/submit \
  -H "Content-Type: application/json" \
  -d '{
    "uuid": "12345678-1234-1234-1234-123456789abc",
    "key": "your-access-key",
    "data": {
      "location": { "latitude": 12.345, "longitude": 67.890 },
      "area": 1000,
      "shape": "rectangle",
      "type": "restoration",
      "speciesData": ["Mangrove", "Seagrass"]
    }
  }'
curl -X POST http://localhost:8080/api/submit -H "Content-Type: application/json" -d "{\"uuid\": \"12345678-1234-1234-1234-123456789abc\", \"key\": \"your-access-key\", \"data\": { \"location\": { \"latitude\": 12.345, \"longitude\": 67.890 }, \"area\": 1000, \"shape\": \"rectangle\", \"type\": \"restoration\", \"speciesData\": [\"Mangrove\", \"Seagrass\"] } }"

Data Format

{
  "location": { "latitude": 12.345, "longitude": 67.890 },
  "area": 1000,
  "shape": "rectangle",
  "type": "restoration",
  "speciesData": [ "Mangrove", "Seagrass" ]
}

Validation Process

  1. Data is submitted via /api/submit
  2. If not from privileged UUID, goes to validation pool
  3. Other peers validate by submitting similar data
  4. If thresholds met within timeout, data is validated and added to blockchain
  5. Credits awarded to original submitter (3) and validators (0.33 each)

Credits

Credits are issued for validated submissions and successful validations.
Check your balance and history via /api/credits.
